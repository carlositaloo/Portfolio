# Portfólio de Projetos em Python

Olá! Sou Carlos Ítalo. Aqui estão projetos que criei para resolver problemas reais do dia a dia, a maioria no trabalho em escola: automações, ferramentas de escritório e utilitários para Windows.

Quase tudo é em **Python**. O `windows-debloater` é em **PowerShell**.

## Projetos

| Projeto | O que faz |
|---|---|
| [atalhos-teclado](atalhos-teclado) | Atalhos de teclado personalizados para abrir programas e agilizar tarefas. [Baixar .exe](https://github.com/carlositaloo/Portfolio/releases/tag/atalhos-v1.0) |
| [automacao-canva](automacao-canva) | Insere nomes de uma planilha Excel em artes do Canva, para gerar certificados em massa. |
| [converter-imagens](converter-imagens) | Converte fotos HEIC (iPhone) para PNG ou JPEG em lote. Usado em mais de 1500 fotos. [Baixar .exe](https://github.com/carlositaloo/Portfolio/releases/tag/converter-heic-v1.0) |
| [corretor-ortografia](corretor-ortografia) | Primeira versão do corretor ortográfico com atalho global (LanguageTool). A versão nova está em [corretor-ortografico-ptbr](https://github.com/carlositaloo/corretor-ortografico-ptbr). |
| [juntar-pdfs](juntar-pdfs) | Junta vários PDFs em um só arquivo, sem o limite dos sites online. |
| [leitor-gabaritos](leitor-gabaritos) | Leitura de gabaritos por imagem para correção de provas. *Projeto incompleto* (versões 1 e 2). |
| [mapa-notas-sige](mapa-notas-sige) | Passa notas de uma planilha Excel para o SIGE (sistema do estado do Ceará). |
| [scangrader](scangrader) | Gera IDs de alunos e corrige resultados de provas a partir de planilhas. |
| [transferencia-notas](transferencia-notas) | Copia as notas do SIGE para um documento Word na ordem certa. |
| [windows-debloater](windows-debloater) | Script PowerShell que remove apps inúteis, desativa telemetria e deixa o Windows mais leve. |

## Como rodar

Cada pasta tem seu próprio código. Em geral:

```bash
pip install -r requirements.txt   # quando a pasta tiver esse arquivo
python main.py
```

Os programas prontos (`.exe`) ficam na aba [Releases](https://github.com/carlositaloo/Portfolio/releases).
